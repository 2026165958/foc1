NOT Logic Gate

This animation shows how a NOT gate works. It flips the input: if the input is ON, the output becomes OFF; if the input is OFF, the output becomes ON.

Beginner-friendly explanation

A NOT gate is like a switch that reverses the signal.

Input = 0  → Output = 1
Input = 1  → Output = 0

If the light is ON, the NOT gate turns it OFF.
If the light is OFF, the NOT gate turns it ON.
