Project 1: AND Gate

An AND gate only gives an output of ON when both inputs are ON. If either input is OFF, the output is OFF.

A = OFF, B = OFF → Output = OFF

Beginner-friendly explanation

The AND gate works like a rule: both switches must be ON before the output turns ON.

A = 0, B = 0 → 0
A = 1, B = 0 → 0
A = 0, B = 1 → 0
A = 1, B = 1 → 1
